# Composants tiers

Cette application utilise **UVCAndroid 1.0.13**, distribué sous licence Apache 2.0.
Le texte de licence est inclus dans `LICENSE-UVCAndroid.txt`.

Le composant UVCAndroid intègre notamment libusb, libuvc, libjpeg-turbo,
libyuv et rapidjson. Leurs mentions et licences restent celles distribuées
avec le projet d'origine : https://github.com/shiyinghan/UVCAndroid
